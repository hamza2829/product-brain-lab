# User stories

| User | Story | Acceptance criteria |
| --- | --- | --- |
| Product manager | I want to ask why a product choice was made so I can explain it without reconstructing several conversations. | The response includes excerpts and links. A citation opens the full record and its related IDs. |
| Product manager | I want to recover what customers said before I write a requirement. | I can restrict a question to interview notes or discussion threads and quote the underlying record. Both date boundaries are inclusive. |
| Chief product officer | I want to check which cohort and measures are in a pilot so I can review its scope. | Each source shows its system, record date, and ID. The app reports insufficient evidence when the selected records fall below its similarity cutoff. |
| Both | I want to signal whether an answer helped so the team can track errors. | A yes or no vote is confirmed after a SQLite write. Changing the vote updates the same answer ID. |
