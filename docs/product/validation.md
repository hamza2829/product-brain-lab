# Validation plan

Recruit about 40 practicing product managers across seniority levels and team sizes, aiming for 32 individual contributors and 8 product leads. Invite participants from teams with different mixes of tickets, written decisions, and chat. Use the same fictional source bundle for everyone. The CPO persona is a hypothesis. Use product leads as an initial proxy for portfolio-review tasks and record that sampling limit.

Give each participant two matched sets of decision, customer-feedback, and pilot-review tasks. One set uses the demo and the other uses manual search of the same records. Alternate the order and swap which set goes with each method. Run about 10 moderated sessions to observe where people get stuck and have the rest complete a timed, unmoderated session. Ask participants to submit the record IDs and explain why the evidence supports their answer.

Score submissions against a task rubric before looking at which method the participant used. Record time to first correct citation, task completion, citation errors, and vote response rate. Cap each task at five minutes and report failures alongside timing. Group problems by query wording, retrieval miss, unhelpful excerpt, or difficulty opening the source. Collect a short follow-up on whether the participant would reuse the workflow.

| Measure | Pilot target |
| --- | --- |
| Evidence task completion | At least 75% of attempted demo tasks end with a correct source and a supported explanation. |
| Time to verified evidence | Median time falls by at least 25% compared with manual search. Include timed-out tasks at the five-minute cap. |
| Citation usefulness | At least 80% of source links opened in observed sessions support the claim the participant used them for. |
| In-app feedback | At least 70% of submitted votes are useful. Report vote coverage and counts because feedback is optional. |

This study is planned. The offline retrieval benchmark uses fictional labels and measures a separate aspect of the prototype.
